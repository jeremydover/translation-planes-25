# Narayana Rao and Satyanarayana Construction

## Reference
Narayana Rao M. L. and Satyanarayana, K., A New Class of Square Order Planes. J. Comb. Theory Ser. A., 35:33-42, 1983. 

## Instance Data
r
=
Type: Integer
Description: An odd integer 1 or larger allowing the construction of a plane of order 5^{2r}

### Example
```json
{"r":3}
```

## Implementation

### Function

narayanaRaoSatyanarayanaImplementation(r);

### Input

r: an odd integer at least 1

### Output

A Magma PlaneProj object modeling the Narayana Rao-Satyanarayana plane.
